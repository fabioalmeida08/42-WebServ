Métodos e rotas

Testes rápidos do comportamento obrigatório.

GET Página estática

Busca este próprio index. Deve vir com Content-Type e Content-Length corretos.

esperado: 200

HEAD Só headers

Mesmos headers do GET, corpo vazio.

esperado: 200 sem body (ou 405, se não suportado)

GET Autoindex

Listagem de diretório gerada pelo servidor.

esperado: 200 com listagem
Abrir

GET Redirect

O fetch segue redirects sozinho; abra o link para ver o navegador ser redirecionado.

esperado: 301/302 + Location
Abrir

POST Body simples

Envia texto puro para a rota de upload.

esperado: 200/201

DELETE Remover arquivo

Apaga um arquivo dentro da pasta de upload.

esperado: 200/204 · inexistente: 404

Upload de arquivos

multipart/form-data para a rota de upload. Os uploads aparecem no histórico abaixo para facilitar o DELETE.

POST multipart/form-data

também dá para usar o form nativo (sem JS)

POST Body grande demais

Gera um corpo 1 byte maior que o client_max_body_size configurado.

esperado: 413

POST Chunked

Envia via stream (Transfer-Encoding: chunked). Só funciona em navegadores com suporte a request streams sobre HTTP/1.1 — se falhar, use o comando do terminal.
